# 운영하면서 신경 쓸 것

## 꼭 지킬 것

- **비밀키는 커밋 금지.** 저장소가 퍼블릭입니다.
  - `.env*`는 `.gitignore`에 들어 있습니다.
  - 키는 Vercel 환경변수에만 넣으세요.
- **키가 유출됐다면**
  - DB: Neon 콘솔에서 DB 비밀번호를 재설정하고, `DATABASE_URL`을 바꾼 뒤 Redeploy하세요.
  - Blob: Vercel Storage에서 토큰을 재발급하세요.
  - `SESSION_SECRET`을 바꾸면 전원이 로그아웃됩니다(쿠키 무효화).
- **배포 직후 본인이 먼저 가입하세요.** 첫 가입자가 관리자가 됩니다.

## 무료 플랜 (2026년 10월 기준)

| 서비스 | 알아둘 것 |
| --- | --- |
| **Neon** (DB) | 5분 동안 안 쓰면 잠들고, 다음 요청 때 1초 이내로 자동으로 깨어납니다. **수동 복구는 필요 없습니다.** 월 100 CU-시간, 저장 0.5~1GB로, 14명이면 극히 일부만 씁니다. 한도를 넘으면 다음 달까지 정지됩니다 |
| **Vercel** (호스팅) | Hobby 플랜은 **비상업용**입니다. 배포는 하루 100회까지 가능합니다. 한도를 넘으면 해당 기능이 30일 정지됩니다(이 규모로는 넘기 어렵습니다) |
| **Vercel Blob** (스크린샷) | 무료 1GB입니다. 업로드할 때 압축(장당 약 100~400KB)하므로 수천 장 여유가 있습니다 |

- **백업:** Neon 무료 플랜의 복구 가능 기간은 6시간뿐입니다. 가끔 `pg_dump "$DATABASE_URL" > backup.sql`로 백업해 두세요.
- **사용량 확인:** Neon 콘솔의 **Usage**와 Vercel의 **Usage** 탭에서 볼 수 있습니다. 둘 다 한도에 가까워지면 메일이 옵니다.

## DB 스키마 변경

- `db/schema.sql`은 **처음 설치할 때** 쓰는 파일입니다. 다시 실행해도 안전하지만, 이미 있는 테이블에 **새 컬럼을 추가하지는 않습니다.**
- 운영 중에 컬럼을 추가하거나 바꾸려면 `alter table ...`을 따로 Neon SQL Editor에서 실행하고, `schema.sql`도 같이 고쳐 두세요.
- Neon의 **Branch** 기능을 쓰면 운영 DB를 복제해서 변경을 먼저 시험해 볼 수 있습니다.

## 동작 규칙 (헷갈릴 수 있는 것)

- **날짜 기준은 한국 시간(KST)입니다.** '오늘', '지난 매치', '경기 당일'을 모두 KST로 판단합니다.
- **매치 카드:** 참여자가 5명 이상인 날에 생기고, 10명이 모이면 "확정"으로 표시됩니다. 10명을 넘는 인원은 "대기"로 표시됩니다.
- **결과(MVP·범인 투표, 스크린샷):** 경기 당일부터 카드에 보입니다.
  - 투표는 그날 참여자만 할 수 있고, 본인에게는 투표할 수 없습니다. 종류별로 1표이며 다시 누르면 취소됩니다.
  - 화면에는 득표수만 보이지만, **DB에는 누가 누구에게 투표했는지가 저장됩니다.** DB에 접근할 수 있는 사람은 볼 수 있다는 뜻입니다.
  - 범인 투표는 팀 구분 데이터가 없어서 **참여자 전체가 후보**입니다. 나중에 팀 나누기 기능을 넣으면 진 팀으로 후보를 좁힐 수 있습니다.
  - 스크린샷은 매치당 10장까지입니다. 삭제는 올린 사람이나 관리자만 할 수 있습니다.
  - 스크린샷 파일은 비공개 Blob에 저장됩니다. 로그인한 멤버만 `/api/screenshots/[id]` 경로로 볼 수 있습니다.
- **카드 삭제(관리자):** 그날의 응답, 세팅, 투표, 스크린샷이 **전부 삭제**됩니다.
- **멤버 삭제(관리자):** 그 멤버의 일정과 투표는 삭제되고, 그 멤버가 올린 스크린샷은 남습니다(업로더 표시는 "탈퇴한 멤버").

## 보안 수준

- **PIN:** 4자리라 강하지 않습니다. 5번 틀리면 5분 동안 잠깁니다. 잊은 멤버는 관리 탭에서 PIN을 초기화하세요.
- **가입:** 링크만 있으면 누구나 가입할 수 있습니다. 배포 주소는 단톡방에만 공유하세요.
  - 막고 싶으면 `src/app/actions/auth.ts`의 `register`에 초대 코드 확인을 추가하면 됩니다.
- **세션:** 30일 동안 유지됩니다.

## 개발 메모

- **DB 코드 구조:** 모든 DB 접근은 `src/lib/repo`를 거칩니다. 실제 서비스는 `postgres.ts`(Neon), 목업 모드는 `memory.ts`를 씁니다.
  - 쿼리를 추가할 때는 `types.ts`의 `Repo` 인터페이스에 먼저 추가한 뒤, 두 구현을 함께 고치세요.
- **목업 모드:** `npm run dev:mock`은 개발 서버에서만 동작하고, `next build`·`next start`·Vercel에서는 자동으로 꺼집니다.
- **Next.js 16:** `middleware.ts`의 이름이 `proxy.ts`로 바뀌었습니다. 버전을 올릴 때는 `node_modules/next/dist/docs/`의 변경 사항을 확인하세요.
- **업로드 크기:** Vercel 요청 본문 한도가 4.5MB라서, 브라우저에서 긴 변 1920px JPEG로 압축한 뒤 올립니다. 서버에서도 4MB 제한을 겁니다.
- **아이콘:** `public/icons/`의 아이콘은 직접 그린 플레이스홀더입니다. Riot 공식 이미지로 바꾸려면 [Riot 법적 고지](https://www.riotgames.com/en/legal)를 확인하세요.
